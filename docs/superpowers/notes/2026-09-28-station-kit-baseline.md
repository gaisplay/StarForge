### 8.2 Мёртвый журнал теперь `INVALID`

В `scripts/regress_evidence.py` функция `run_engine` отдаёт журнал через `live_log`. Та признаёт запуск
мёртвым, если выполнено хотя бы одно из трёх условий:

- в журнале нет ни одной строки `LogStarForge`;
- нет строки `Bringing World`;
- есть `Engine exit requested (reason: ConsoleCtrl`, на любом кадре.

Если мёртв первый запуск, вердикт — `INVALID`. Если второй — `CHANGED?`: у сценария это вердикт для
второго повтора, который не прочитан. Сравнитель судит `CHANGED?` строками `.now`, как `CHANGED`. На
каждый мёртвый запуск сценарий печатает `dead run:` с причинами. Номера строк сценария, на которые
ссылаются спека и план, не сдвинулись: функция дописана в конец файла, а шапка переписана без
изменения числа строк.

Проверка на всех журналах, что есть. Из 620 `.now.log` и `.again.log` пяти проходов мёртвыми признаны
ровно два — оба повтора этого раздела. Из 117 опорных журналов улик — ни один.
