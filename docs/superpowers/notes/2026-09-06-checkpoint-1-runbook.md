# Точка проверки 1 — порядок действий

Стенд собран и собирается без ошибок. Осталось два действия, которые нельзя
автоматизировать: создать пустой уровень и провести замер.

**Что мы выясняем.** Может ли персонаж стоять и ходить внутри корабля, летящего
на 400 м/с и крутящегося на 180°/с. От ответа зависит, продолжаем ли мы по
основному плану или переключаемся на запасной вариант из §12 спеки, который
дороже.

**Сколько это займёт.** Уровень — минута, один раз навсегда. Замер — три минуты.

| Проверить | Как |

## Шаг 1. Создать уровень — один раз

Открыть редактор:

```bash
"C:/Program Files/Epic Games/UE_5.8/Engine/Binaries/Win64/UnrealEditor.exe" "F:/UEProject/StarForge/StarForge.uproject"
```

Он пожалуется, что карта `/Game/Maps/L_FrameSpike` не найдена, и откроет пустышку.
**Так и задумано** — конфиг уже указывает на карту, которой пока нет.

В редакторе:

```
File → New Level → Empty Level
File → Save Current Level As → папка Maps, имя L_FrameSpike
```

Уровень должен остаться **пустым**. Ничего на него ставить не надо: корабль,
персонаж и приборная панель создаются кодом при запуске. Пустой уровень — это и
есть правильный уровень.

Закрыть редактор. Закоммитить:

```bash
git add Content/Maps && git commit -m "feat(spike): add the empty level the rig assembles itself into"
```

После этого шаг больше никогда не понадобится — карта поедет вместе с репозиторием.

## Шаг 2. Запустить

```bash
"C:/Program Files/Epic Games/UE_5.8/Engine/Binaries/Win64/UnrealEditor.exe" "F:/UEProject/StarForge/StarForge.uproject" -game -windowed -ResX=1600 -ResY=900
```

Ты окажешься от первого лица внутри серой коробки 8×8×8 метров. Коробка — это
корабль, и он уже летит: скорость меняется по синусоиде с периодом 8 секунд, крен
идёт постоянно, тангаж и рысканье качаются. За стенами ничего нет, звёзд нет —
это стенд, а не игра.

**Управление:** `W A S D` — ходьба, стрелки — обзор. Больше ничего не назначено.

## Шаг 3. Замер

Строго по порядку. Первый пункт важнее остальных вместе взятых.

**1. Стоять минуту.** Убрать руки с клавиатуры. Не двигаться, не крутить обзор,
не сворачивать окно. Смотреть на строку `measured` — она должна дойти до 55
секунд без сброса. Любое нажатие обнуляет интервал и начинает отсчёт заново.

Когда `measured` перевалит за 55 — записать `drift peak` и `jitter peak`.

**2. Походить.** Пройтись на WASD вдоль стен, попробовать углы. Смотреть, не
проваливается ли персонаж сквозь пол и не залипает ли в стенах. Ходьба сбросит
интервал замера — это нормально, числа уже записаны.

**3. Покрутить обзор.** Стрелками. Проверить главное: **стоит ли интерьер
неподвижно перед глазами**, пока корабль вращается. Стены должны оставаться на
месте, как в комнате. Если комната уезжает из-под взгляда — это отказ.

**4. Отметить самочувствие.** Можно ли этим пользоваться, попадаешь ли мышью в
точку, не укачивает ли.

## Что на экране

Сверху вниз, как рисует панель:

| Строка | Что означает |
|---|---|
| `elapsed` | Время с запуска. **Не** время замера |
| `drift now` | Текущее смещение от точки отсчёта, см |
| `drift peak` | **Главное число.** Худшее смещение за интервал. Бюджет 1.0 см |
| `measured` | Сколько секунд непрерывного замера набрано. Нужно 55 |
| `jitter peak` | Дрожание за один тик. Если заметно глазом — отказ |
| `ship-local position` | Где стоишь в координатах корабля |
| `ship speed` | Скорость корабля, м/с. Дойдёт до 400 |
| `angular rate` | Угловая скорость, ~216°/с постоянно |
| `felt acceleration` | Ощущаемое ускорение. **Будет выше предела почти всегда — см. ниже** |

### Красные строки

Появление любой из них обесценивает всё, что выше:

| Строка | Значение |
|---|---|
| `NO SFCHARACTER POSSESSED` | Сцена не собралась, пешки нет |
| `NO SHIPBOARD MOVEMENT COMPONENT` | Персонаж есть, но не тот |
| `NO SHIP FRAME BOUND` | Корабль не найден, персонаж в мировых координатах |
| `CARRY SKIPPED n ticks` | Опора терялась. Числа относятся к более раннему моменту |
| `CARRY NOT RUNNING` | Опора потеряна **прямо сейчас**. Замер стоит |

### Цвета вердикта

| Цвет `drift peak` | Значение |
|---|---|
| жёлтый | Времени ещё не набрано, вердикта нет |
| зелёный | Набрано **и** уложились в бюджет |
| красный | Набрано и не уложились |

## Два правила чтения

**Правило первое: сначала время, потом увод.** Нулевой увод получается и когда
стенд отстоял минуту идеально, и когда он не сделал ни одного замера. Само число
их не различает — различает только `measured`. Если там меньше 55, всё остальное
на экране ничего не значит.

**Правило второе: `felt acceleration` выше предела — не дефект стенда.** Крен
180°/с в каюте радиусом 4 метра даёт около 4 g у стены, вдвое выше порога
гравиплит, который назначает сама спека. Это противоречие внутри дизайна, а не
поломка. Оно требует твоего решения, но на исход этого замера не влияет.

## Если что-то пошло не так

Таблица симптомов — в [плане](../plans/2026-09-06-frame-spike.md), раздел
«Точка проверки 1». Два самых вероятных:

**Персонажа кувыркает, цифры замерли.** Первый подозреваемый — выравнивание
гравитации по кораблю не сложилось с телепортом переноса. Это единственное
допущение всей ветки, не проверенное ничем, кроме этого прогона. **Не спеши
объявлять провал разложения движения** — сначала проверь это.

**Интерьер уезжает из-под взгляда.** Зажим камеры. Он снят в `SFCharacter::BeginPlay`,
проверить, что снятие подействовало.
